# 적용한 공통 규칙

- 표준: https://github.com/eigger/hass-repo-standards/tree/v0.1.1
- 버전: 0.1.1
- 채택일: 실제 채택 PR 날짜 입력
- profile: integration / unit 또는 integration / ha 중 선택
- 실제 기본 브랜치: 채택 시 입력
- 최소 HA 검증 환경: HA/Python/플러그인 버전 또는 미검증 사유
- 최소 package 검증: 해당 package와 버전

## 예외

| 규칙 ID | 이유 | 담당자 | 재검토 조건 |
|---|---|---|---|

예외가 없으면 '없음'으로 명시합니다. 이 템플릿의 미입력 항목을 완료로 표시하지 않습니다.
