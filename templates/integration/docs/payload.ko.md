# Payload 안내

[README](../README.ko.md) | [English](payload.md) | **한국어**

## 공통 payload 안내

공통 문법·요소·속성·예제·색상·회전·디더링은 [imagespec payload 안내](https://github.com/eigger/imagespec/blob/main/docs/payload.ko.md)를 확인하세요.

## 이 통합에서 payload 사용

REPLACE_ACTION_DETAILS: 실제 지원 액션·대상 선택·중첩 payload 위치와 통합의 실제 템플릿 준비·사용 경로를 적습니다. 기존 동작 안내를 보존하며 템플릿을 채우려고 액션을 만들지 않습니다.

## 최소 동작 예제

[실행 가능한 액션 YAML](../examples/payload/minimal.yaml)

REPLACE_EXAMPLE_DETAILS: 연결된 전체 액션 YAML의 실제 모델·대상·컨텍스트·기대 결과를 설명합니다. 양언어는 같은 등록 파일을 사용하며 라이브러리의 bare 요소 목록과 HA 액션 틀을 구분합니다. 실제 목록/YAML 문자열 입력 API를 보존하고 실제 액션 YAML 입력에 맞게 payload_format을 등록하고 실제 schema 정규화 결과를 확인합니다.

## 기기 출력 설정

REPLACE_OUTPUT_DETAILS: 실제 모델 크기·최종 출력 크기·지원 팔레트·회전 모드/디더링·폰트 조회·기기/용지 제한을 적습니다. 호스트 액션 필드와 내부 렌더러 옵션은 구분합니다.

## 지원 기능과 제한

REPLACE_FEATURE_DETAILS: 실제 설치 버전의 요소/extras·템플릿·폰트/이미지/히스토리 제공·기기 제약을 적고 미지원·해당 없음의 이유를 밝힙니다. 절을 채우기 위한 새 기능·config entry를 만들지 않습니다.
