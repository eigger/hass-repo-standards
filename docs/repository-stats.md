# Home Assistant repository statistics

**English** | [한국어](repository-stats.ko.md)

[Main README](../README.md) · [Standards adoption status (Korean)](adoption-status.md)

Statistics for eigger's Home Assistant integrations, related projects and shared libraries `blesession` and `imagespec`. Each numeric cell uses a Shields.io badge that reads GitHub data. **Versions and counts are referenced dynamically, without storing their values in this document.** No token, scheduled workflow or statistics update commit is required. Shields.io and GitHub image caches can delay changes; reload an open page to see refreshed images.

## Metrics

| Metric | Source and meaning |
|---|---|
| Version | Tag of the latest stable GitHub Release, selected by publication date (`sort=date`), excluding prereleases. It can differ from the default branch manifest version or a standalone Git tag. |
| Downloads | Combined download counts of all assets attached to the latest stable GitHub Release. Automatically generated Source code ZIP/tarball archives, git clones and distribution paths without release assets are excluded. |
| Stars | Current GitHub repository star count. |
| Forks | Current GitHub repository fork count. |

HACS downloads of a GitHub release asset contribute to that asset's GitHub download count. However, [HACS Downloads (Korean)](documentation.md) counts the target asset in the release selected by HACS, so its scope differs from the **all assets total of a release** shown here. Do not add these counts or interpret them as active installations or unique users. README badges for HACS Default integrations continue to use official HACS data under DOC-05.

Missing releases or failed requests may produce badge states such as `no releases`, `not found` or `invalid`; these do not mean zero downloads or version zero. Click a badge to inspect the repository's releases, stargazers or forks.

## Scope and data sources

The user-selected list covers 22 integrations, two related projects and two shared libraries in public `eigger` repositories. `hass-cyx-rgb-led`, `hass-gicisky`, `hass-divoom`, `hass-imagespec-card`, `hassble-config`, `hassio-apps` and `hass-repo-standards` are excluded from this statistics table. These statistics are independent of standards adoption status. **Values refresh automatically; adding, renaming or removing repositories requires updating the rows and reference URLs in both language versions.**

Badge contracts: Shields.io [Release](https://shields.io/badges/git-hub-release), [latest release downloads](https://shields.io/badges/git-hub-downloads-all-assets-latest-release), [Stars](https://shields.io/badges/git-hub-repo-stars) and [Forks](https://shields.io/badges/git-hub-forks). Shields.io manages each badge's cache policy.
