# Home Assistant 리포별 현황

[English](repository-stats.md) | **한국어**

[메인 README](../README.ko.md) · [공통 규칙 적용 현황](adoption-status.md)

eigger의 Home Assistant 통합과 관련 프로젝트, 공통 라이브러리 `blesession`·`imagespec`을 모았습니다. 각 수치 셀은 GitHub 데이터를 읽는 Shields.io 동적 배지입니다. **버전과 수치를 문서에 저장하지 않고 동적으로 참조합니다.** 별도 토큰·예약 workflow·수치 갱신 커밋이 필요하지 않습니다. Shields.io와 GitHub 이미지 캐시에 따라 반영이 지연될 수 있으며 열린 페이지는 다시 불러와야 할 수 있습니다.

## 집계 기준

| 항목 | 참조와 의미 |
|---|---|
| 버전 | GitHub의 최신 정식 Release 태그. 게시 날짜 기준(`sort=date`)이며 prerelease는 제외합니다. 기본 브랜치 manifest 버전이나 단순 Git 태그와 다를 수 있습니다. |
| GitHub 누적 다운로드 | 모든 릴리스에 첨부된 모든 asset의 다운로드 수 합계. 자동 생성 Source code ZIP/tarball·git clone·첨부 파일이 없는 배포 경로는 포함하지 않습니다. |
| 스타 | GitHub 리포의 현재 스타 수. |
| 포크 | GitHub 리포의 현재 포크 수. |

HACS를 통한 GitHub 릴리스 첨부 파일 다운로드도 해당 GitHub asset의 다운로드 수에 포함됩니다. 다만 [HACS Downloads](documentation.md)는 HACS가 선택한 릴리스의 대상 asset 다운로드 수이므로, 이 표의 **모든 릴리스·모든 asset 합계와 범위가 다릅니다.** 두 수치는 더하지 않으며 활성 설치 수·고유 사용자 수로 해석하지 않습니다. HACS Default 통합의 README 배지는 기존 DOC-05대로 HACS 공식 데이터를 사용합니다.

릴리스가 없거나 조회가 실패하면 배지에 `no releases`, `not found`, `invalid` 등의 상태가 표시될 수 있으며 버전이나 다운로드가 0이라는 뜻이 아닙니다. 배지를 클릭하면 해당 리포의 릴리스·스타·포크 원본 화면을 확인할 수 있습니다.
